# Manual Test Assets

Thư mục này gom toàn bộ tài sản test thủ công để root, `backend/`, và `frontend/` không còn lẫn script/test rời rạc.

- `tests/manual/backend/`: checklist, `.http`, PowerShell notes, và fixture manual test cho backend.
- `tests/manual/scripts/`: script smoke test và script kiểm tra thủ công ở mức repo.
- `tests/manual/fixtures/`: fixture dùng chung cho script/test thủ công.

Automated test suite chính của backend vẫn nằm ở `backend/src/tests/`.
