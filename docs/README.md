# Documentation Map

Tài liệu của dự án hiện được gom theo cụm để root gọn hơn và dễ tra cứu hơn:

- `docs/AI/`: tài liệu AI, migration, quiz generator, hướng dẫn cho agent.
- `docs/analysis/`: phân tích hệ thống, overview, ghi chú kiến trúc.
- `docs/operations/`: Docker, Git workflow, hướng dẫn vận hành.
- `docs/plans/`: kế hoạch triển khai, TODO, test plan ở mức dự án.
- `docs/reports/`: báo cáo trạng thái và summary.
- `docs/archive/`: ghi chú cũ hoặc tài liệu tham khảo không còn ở luồng chính.

Tài liệu theo ứng dụng được giữ gần source:

- `backend/docs/`: tài liệu backend, setup, testing, status, AI backend.
- `frontend/docs/`: tài liệu frontend và tài liệu lưu trữ của frontend.

Manual test assets được gom riêng tại `tests/manual/`.
